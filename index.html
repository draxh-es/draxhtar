In an age when most heroes fought far above the hardware, a young wanderer went down instead, to the registers, the buses and the bits, and swore an oath: to make machines talk to each other.

Since then I have forged firmware for STM32 boards, taught pressure sensors to speak CANopen, built a pub/sub system from raw sockets, and brought up Linux on automotive hardware with Yocto. I care about clear C, careful wiring, and documentation the next person can actually follow.

When I'm not chasing bugs with a debugger and a logic analyzer, I keep sharpening my C one lesson at a time, and I'm always looking for new quests to join.

— signed by my own hand, Draxhtar

QUEST LOG

Completed quests, ordered by rarity of loot.

LEGENDARY

BCT 22 CANopen Reader

An STM32 HAL module that reads an ATEK BCT 22 pressure sensor straight off the CAN bus over CANopen.

  • C
  • STM32
  • CANopen

REWARD: 2500 XP

SOURCE ↗

The sensor speaks only CANopen, so I learned its tongue. The module wakes it with an NMT start, turns its PDOs into bar, notices when it falls silent or reboots and brings it back, and keeps every EMCY it sends. SDO and LSS tools for the first bench setup ride along, with a step-by-step guide for the rest of the team.

EPIC

BCT 22 Pressure Node

An STM32F4 node that measures a 4-20 mA pressure transmitter and sends it out as CAN frames.

  • C
  • STM32F4
  • ADC
  • CAN

REWARD: 1800 XP

SOURCE ↗

Half of this quest was copper, not code: the current loop, the shunt resistor, the RC filter and the clamp in front of the ADC, then an SN65HVD230 to reach the bus. The other half turns millivolts into bar and bar into CAN frames, with every design choice, CAN ID and test step written down.

EPIC

My DDS Prototype

A tiny DDS-style publish/subscribe system built from scratch on raw UDP sockets, with topics and discovery.

  • C++
  • UDP
  • Sockets
  • DDS

REWARD: 1600 XP

SOURCE ↗

Before trusting Fast DDS, I wanted to know what it does under the hood. So I built my own: writers and readers that talk on topic IDs, and a herald that announces every participant on a discovery channel so the others can find it. Just POSIX sockets.

Cmaster

A step-by-step path from C fundamentals to systems and embedded engineering, one lesson at a time.

  • C
  • Make
  • ASan

An ongoing training quest. Every lesson is a set of TODO stubs with its own test harness, built with strict warnings plus AddressSanitizer and UBSan, so no memory bug escapes. Pointers, strings, file I/O, bit tricks, data structures, all the way down to bare metal.

My STM32F429 projects: CubeIDE experiments, linker scripts, startup code and a hand-written HAL library.

Where every embedded knight starts: blinking LEDs, then floats and sizeof, then a HAL of my own. Next to it, StmCcodes holds dozens of small drills in bit masks and register-style C. Not glamorous, but every later quest stands on this ground.

Kilo Editor

A fork of antirez's kilo: a terminal text editor in under 1000 lines of C, with no curses.
